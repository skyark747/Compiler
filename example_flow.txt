🎓 KEY CONCEPTS EXPLAINED:
═══════════════════════════════════════════════════════════════════════

1. SYMBOL TABLE = Phone Book for Variables
   • Stores: variable name → {type, scope}
   • When you use "a", checker looks it up to find type

2. FUNCTION TABLE = Phone Book for Functions
   • Stores: function name → {return_type, parameters}
   • When you call add(a,b), checker looks it up to verify

3. SCOPE = Room Number
   • Global scope = 0 (everyone can see)
   • Function scope = 1, 2, 3... (private to that function)
   • When function ends, its variables are deleted

4. TYPE CHECKING = Matching Game
   • int + int = int ✓
   • int → float = OK (with warning)
   • float → int = ERROR ✗

5. FLOW = Assembly Line
   • Step 1: Register all functions (so they can call each other)
   • Step 2: Check each function's body (one at a time)
   • Step 3: Clean up after each function
   • Step 4: Report results
